# 🥗 Frozen Fitness - Professional E-commerce Migration

A high-performance, modern reimagining of the **Frozen Fitness** e-commerce platform. This project represents a complete architectural migration from legacy procedural PHP to a robust, scalable **Laravel** ecosystem, focusing on portability, maintainability, and a premium user experience.

### 🚀 Architecture & Tech Stack

*   **Core:** [Laravel 11](https://laravel.com/) & [PHP 8.3](https://www.php.net/)
*   **Database:** [SQLite](https://www.sqlite.org/) (optimized for zero-config portability)
*   **Frontend:** [Tailwind CSS v4](https://tailwindcss.com/) & [Vite](https://vitejs.dev/)
*   **Server:** [Nginx](https://www.nginx.com/) on [DigitalOcean VPS](https://www.digitalocean.com/)
*   **Authentication:** [Laravel Breeze](https://laravel.com/docs/11.x/starter-kits#laravel-breeze) (customized)

### ✨ Key Features

*   🛒 **E-commerce Engine:** Full-featured shopping cart system with session-persistent logic.
*   📦 **Order Lifecycle:** Automated checkout process transforming session data into relational order records.
*   🛡️ **Admin Dashboard:** Comprehensive CRUD management for Meals, Diets, Ingredients, and Categories.
*   🌍 **English-Only Architecture:** Complete migration and normalization of legacy Portuguese data into a clean English schema.
*   🖼️ **Asset Management:** Integrated image processing for products and ingredients with responsive delivery.

### 🛠 Engineering Standards

*   🏗️ **Solid MVC:** Strict adherence to Model-View-Controller patterns for clean separation of concerns.
*   🧹 **Clean Code:** Implementation of PSR-12 standards and descriptive naming conventions.
*   📜 **Conventional Commits:** History managed through atomic, semantic versioning principles.
*   🎨 **UI/UX Excellence:** Dark Mode standardization and responsive design using Tailwind CSS v4.
*   💾 **Portability:** Self-contained SQLite database ensuring immediate deployment and testing.
